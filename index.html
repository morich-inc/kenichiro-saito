MNTSQ株式会社は、すべての合意をフェアにするというビジョンのもと、契約・法務業務をテクノロジーで変革するリーガルテック企業。

契約の作成・審査・管理からナレッジ化までを一気通貫で支援するMNTSQ CLMを展開し、トヨタ自動車、三菱商事、ENEOS、三井住友銀行など、日本を代表する大手企業への導入実績を有しています。特に、日本を代表する大手企業の41%が導入済みという圧倒的な実績を誇り、エンタープライズ領域における高い信頼性と市場浸透力が大きな強みです。

【MNTSQの本質——「AI×SaaS」ではなく「契約のプラットフォーム」】

MNTSQは、いわゆる「AI×SaaS」のスタートアップではありません。目指すのは契約のプラットフォームであり、現在地はその前提となる大手企業の法務部向け業務プラットフォームです。

ベンチマークはSalesforce・Workday・SAP——法務の世界はエンプラ基幹システムの最後の空白地帯であり、会計（SAP）・人事（Workday）・CRM（Salesforce）のような王者が不在のなかで市場を創っています。

  • 現在：大手企業の法務部向け業務プラットフォーム 契約業務をMNTSQ上で完結させる。10→1000で勝つフェーズ
  • 次：大手企業の契約プラットフォーム 法務部→事業部へ展開。LLMにより「事業部向けLegalTech」という新市場が爆誕
  • 将来：契約交渉プラットフォーム／契約のインフラ 対外的な契約交渉まで含む社会インフラ。契約件数年間5億件×1通1,000円で5,000億円規模

【募集背景】

採用の最優先がエンジニアからGTMへシフトした——今、MNTSQのマーケティングが最も面白いフェーズ

私たちMNTSQ（モンテスキュー）は、「すべての合意をフェアにする」というビジョンのもと、2020年の"リーガルテック元年"から5年間、エンタープライズ企業を中心に導入を拡大してきました。

一方で、市場の成長が加速する今、次の5年でさらなるシェア拡大を実現するためには、競合との差別化をより鮮明にし、成長スピードを一段階引き上げる必要があります。これまでの営業力に頼った成長だけでなく、マーケティング戦略によって市場をリードしていく体制を構築するため、今回、企画をつくりだし、事業成長のエンジンとなるマーケティングプランナーを募集します。

オープンワーク株式会社は、「働きがいをすべての人へ」をミッションに、日本の労働市場へ透明性をもたらすHR Tech企業です。

2007年に創業者・増井慎二郎氏が立ち上げた「Vorkers」を起点に、2019年に「OpenWork」へリブランディング。現在は国内最大級となる1,300万件超の社員クチコミ・評価スコアを蓄積し、個人が主体的に企業を選ぶためのキャリアプラットフォームへ成長しています。

2022年12月には東証グロース市場へ上場。近年は「OpenWorkリクルーティング」が利用企業1,000社を突破し、学生ユーザー数も過去最多の32万人へ到達するなど、採用支援領域での存在感も拡大。さらに、クチコミデータを資本市場分析や組織課題解決に活用するオルタナティブデータ事業も前期比134％成長を実現しています。

AIと専門スタッフによる二重審査でクチコミ品質を担保するユーザーファーストの姿勢を強みに、LINE、博報堂、マッキンゼー、Amazonなど多様な出身者が集うフラットな組織文化のもと、日本の"働きがい"そのものを変革する挑戦を続ける企業です。

【募集背景】

2007年にサービスを開始したOpenWork。業界最大級の社員クチコミサイトとして成長しており、ユーザー登録は約758万人を突破し、約2,010万件のクチコミ評価スコア数を保有しています。クチコミの量だけではなく、「健全性」にこだわって運営してきました。

そんな弊社が掲げているミッションが、「ひとりひとりが輝く、ジョブマーケットを創る」です。

  • 求人票や企業の採用ホームページなどだけではわからない、企業のリアルな実態を開示することによりジョブマーケットの透明性を高めること
  • 個人が主体的にキャリアを選択し、ミスマッチのない転職を実現すること
  • 誠実な経営を行う経営者に人が集まる世界を創ること

を目指しています。

これまで、社員クチコミで事業は順調に成長していました。ただ、労働市場全体を見渡したときの影響力はまだ小さく、個人・企業の行動変容を起こすまでには至っていません。

そこで、10数年かけて蓄積してきた｢社員クチコミ｣のジョブデータと、｢採用情報｣をつなげ、企業側から収益を得るビジネスモデル「ダイレクトリクルーティングサービス」の展開・強化に舵取りしました。

BtoBマーケティングに関しては、まだまだ発展途上の成長段階となっています。今後、他社にはないオープンワークの魅力を市場に伝えること、またコンサルタントと連携しマーケティングの力で顧客の成功体験をサポートすることを目指しています。

【具体的な業務内容】

OpenWorkリクルーティングサービスを中心としたBtoBマーケティングの全体を管理いただきます。Q毎に決められたKPIを達成するために、外部講演、共催セミナー、メール、広告、展示会、自社イベント等、様々な施策の立案〜実行〜検証、また施策に必要なコンテンツ制作をメンバーやパートナー企業と回していただきます。業務の内製化の検討及び実施、生産性の向上をおこなうためのテクノロジー活用の推進もおこないます。

【活用ツール】

  • リード管理/SFA/CRM：Salesforce、Account Engagement
  • 分析ツール：GA4、Clarity、Tableau、GTM
  • クリエイティブ制作：AdobeCC
  • マーケ施策実施：ウェビナー管理ツール、Web接客ツール
  • コミュニケーション：zoom、Slack

【部署体制】

所属するのはtoBマーケティングユニットで、商談獲得を目標としたチームになります。toBマーケティングユニットは、マーケティングとインサイドセールスが一緒となった組織です。マネジャー1名、正社員5名、派遣社員2名、複数のパートナー企業の業務委託で構成されています。（現在マーケターは4名）

【魅力】

  • これから拡大していく組織のコアメンバーとして、ビジネスに寄与していくことができる
  • デジタルマーケティングでの改善余地が大きい領域のため、最新アプローチやこれまでの手法にとらわれないマーケティング施策など、様々なチャレンジを通じて成長することができる
  • 日本の労働市場全体に影響を与える可能性を秘めたプロダクトだからこそ、成長と共に社会貢献を実感できる

必須要件：

  • MUST BtoBマーケティング経験5年以上目安
  • MUST マーケティング業務の中で、以下のような取り組みのオーナーとしての運用実績が3つ以上ある（広告運用、メルマガ運用、セミナー運用、展示会出展、外部講演参加、Webサイト制作/改善、SNS運用、SEO運用、ホワイトペーパー制作、データ分析等）
  • MUST 5名以上の組織をマネジメントした経験がある（評価、育成など）

歓迎要件：

  • WANT マーケティングツールの活用やデータを基にした取り組みが推進できる
  • WANT 法人向けのオウンドメディアの立ち上げや成果創出経験あり
  • WANT マーケティングテクノロジーの理解や実装に長けている
  • WANT マーケティングデータの分析経験がある
  • WANT HR業界のマーケティング経験がある
